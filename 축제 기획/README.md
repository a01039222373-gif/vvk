# 축제 기획안 만들기

축제 컨셉과 조건을 적으면 축제 이름, 프로그램, 일정표, 공간 구성, 홍보, 예산안, 운영 계획, 위험 대응, 성과 지표까지 담은
기획안 초안을 바로 만들어 주는 React(Vite) 웹사이트.

**AI나 API 키를 쓰지 않는다.** 브라우저 안에서 테마 템플릿과 계산만으로 기획안을 만들기 때문에 서버·환경변수·비용이 없다.

## 동작 방식

- `src/themes.js` — 테마 10개(먹거리, 음악·공연, 전통·역사, 자연·친환경, 가족·어린이, 야간·빛, 농특산물·수확, 반려동물, 체험·스포츠, 예술·공예)의
  키워드, 이름 재료, 슬로건, 프로그램, 공간, 위험 요소, 예산 가중치
- `src/planner.js` — 컨셉 문장에서 테마를 고르고(최대 2개), 입력값으로 기획안을 계산해 Markdown으로 만든다
  - 일정표: 시작일·기간에 맞춰 낮/저녁 프로그램을 배치 (야간 테마는 늦은 시간대)
  - 예산안: 기본 비율에 테마 가중치를 더해 총예산을 나누고, 합계가 총예산과 정확히 맞게 조정
  - 운영 인원·화장실: 동시 체류 인원(하루 방문객의 40%) 기준으로 계산
  - 위험 요소: 계절(시작일 기준, 없으면 오늘 기준) + 공통 + 테마별
- `src/App.jsx` — 입력 화면과 결과 표시

같은 입력이면 같은 기획안이 나오고, **다른 안 보기**를 누르면 이름·슬로건·프로그램 조합이 바뀐 다른 초안이 나온다.
값을 정하지 않은 항목은 "(가정)"으로 표시된다.

테마를 늘리거나 프로그램을 바꾸고 싶으면 `src/themes.js`만 고치면 된다.

## 내 PC에서 실행

1. 이 폴더에서 `npm install` 후 `npm run dev`
2. http://localhost:5174 접속 (상품 관리 앱의 5173과 겹치지 않도록 5174 사용)

## Vercel 배포

1. 이 저장소를 GitHub에 push
2. https://vercel.com 에서 **Add New → Project** → GitHub 저장소 `vvk` 선택(Import)
   - 상품 관리 앱과는 **별도의 Vercel 프로젝트**로 하나 더 만든다
3. **Root Directory** 를 `축제 기획` 으로 지정 (Framework Preset은 Vite로 자동 인식)
4. 환경변수는 필요 없음. 바로 **Deploy**

## 기능

- 컨셉 입력 (예시 컨셉 버튼 제공)
- 테마 자동 선택 + 직접 선택 (최대 2개)
- 조건: 장소, 시작일, 기간(1~7일), 총예산, 하루 방문객, 주요 대상, 추가 요청
- 다른 안 보기, 복사, `.md` 저장, 인쇄(기획안만 출력)
